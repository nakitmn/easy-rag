# RAG — память системы

Локальный dev-тул для **семантического поиска по коду лаунчера** (VR Club Launcher,
C#/Unity). Назначение — отвечать на вопросы вида «как работает X» по кодовой базе.
Python, llama-index 0.14.x. Вне Unity-приложения (отдельный tooling).

## Каталоги памяти

- `architecture.md` — конвейер, компоненты, метаданные чанка, расширение языков
- `usage.md` — установка, env-переменные, CLI-аргументы, примеры запуска
- `roadmap.md` — что готово, что осталось (шаг 2: embedding + векторная БД), риски

## Структура `RAG/`

```
RAG/
  ast/                       ← домен AST-чанкинга
    scripts/
      config.py              ← ЕДИНСТВЕННАЯ точка конфигурации: чтение/валидация корневого .env
      ast_llamaindex.py      ← шаг 1: AST-нарезка + enrichment (только импортируется шагом 2)
      build_index.py         ← шаг 2: ингест → векторный индекс (инкрементально)
      query.py               ← шаг 2: вопрос → top-k чанков → ответ LLM (query-домен)
      llm_provider.py        ← фабрика LLM по доменам (enrichment/query); конфиг — из config.py
    data/
      ast_chunks.jsonl       ← дебаг-артефакт шага 1 (runtime)
      vector_index/          ← персистентный векторный индекс (runtime, gitignored)
  repomix/                   ← домен repomix (упаковка репо в XML; альтернативный источник)
  requirements.txt
  .memory/                   ← этот каталог
```

## Состояние (на 2026-09-08)

- **ПОЛНЫЙ ПРОГОН КОРПУСА СДЕЛАН — система в рабочем состоянии** (2026-09-08):
  1634 файла → 1634 чанка → 1634 вектора (enriched, 0 потерь), прерывание на
  батче 16 пережито персистом (перезапуск продолжил с места остановки);
  дубли от прогонов по подпапке вычищены `--prune` (итог 1:1:1). Sanity-
  retrieval на доменах вне Chat (VPN/WebView/T9) — релевантные top-5.
  `RAG_TOP_K` поднят до 20. `query.py` готов к использованию; дальнейшее —
  улучшения по запросу (реранкер, MCP-доступ, фильтры). Детали — roadmap.md.
- **Батч-персист в `build_index.py` реализован и верифицирован** (2026-09-08):
  батчи по `RAG_BATCH_SIZE` (env/CLI `--batch-size`, дефолт 50), персист после
  каждого батча, деградация упавшего батча до per-file (битые файлы →
  `files_failed`, ретрай повторным прогоном), guard от полного outage (10
  подряд неудач → стоп), финальный безусловный персист (флаш prune). Падение
  прогона теряет максимум текущий батч, resume бесплатный (docstore-дедуп).
  Верифицировано оффлайн (смоук/no-op/изоляция отказа/prune-флаш/kill-resume)
  и enriched-прогоном Chat (48/48, retrieval = эталон). Полный прогон корпуса
  разблокирован. Детали — roadmap.md.
- **Конфигурация консолидирована в корневом `.env`** (2026-09-07): единственный
  модуль чтения/валидации env — `RAG/ast/scripts/config.py` (6 групп,
  контекстная валидация); дефолтов tunable-параметров в коде нет, legacy
  `GLM_*`/scripts-.env удалены; коммитится шаблон `.env.example`. Самопроверка:
  `.venv/bin/python RAG/ast/scripts/config.py`. Поведение не менялось
  (no-op-прогон — 0 processed; retrieval байт-в-байт). Детали — roadmap.md.
- **Оба LLM-домена переведены на z.ai `glm-5.3-flash`** (2026-09-07): env
  `RAG_ENRICHMENT_*` и `RAG_QUERY_MODEL` в корневом `.env` (coding-эндпоинт,
  один ключ Coding Plan на оба домена). LM Studio больше не нужна для
  enrichment (код-дефолты удалены при консолидации конфигурации). `glm-4.7-flash` у z.ai не существует;
  сравнение с `glm-4.5-air` — 5.3-flash в ~2.5-3 раза быстрее и компактнее
  (детали в roadmap.md). Смена модели не инвалидирует индекс: неизменённые
  файлы не переобогащаются (нужен `--reset` для полного переобогащения).
- **Полный тест Chat на 5.3-flash верифицирован** (2026-09-07, `--reset` ×2):
  48/48 чанков/enriched, 0 CJK, 0 дублей, 0 «эха». Первая сборка дала
  регресс retrieval (мусорный top-1) из-за verbose-summary — промпт
  `CODE_SUMMARY_PROMPT` ужат до 1–2 предложений / ≤40 слов (18–39, avg 30),
  после пересборки (2.9 мин) **retrieval = эталон 2026-09-04**: top-1
  ChatProjectInstaller (0.621) и ChatSendMessagePresenter (0.588). Нюансы:
  кириллица в 1 summary — цитаты литералов кода (не дрейф); 4 чанка теряют
  завершающий `\n` (артефакт CodeSplitter). Детали в roadmap.md.

- Нарезка: `RAG_CHUNK_MAX_CHARS=400000` — файл ≤10K строк не режется,
  **1 чанк = 1 файл**, сироты невозможны по построению. Поддержка: только C#
  (.cs); kt/java/js — закомментированные заглушки реестра.
- Enrichment — **на английском** (русский вывод отменён): summary strictly
  English, keywords — идентификаторы из кода (+явный запрет «эха» категорий
  из промпта: регресс 24/48 → 0). Проводник — z.ai glm-5.3-flash
  (исторически: LM Studio qwen2.5-7b-instruct через `scripts/.env` с `GLM_*` —
  удалено при консолидации конфигурации).
- **Полный прогон Chat верифицирован** (2026-09-04): 48 файлов → 48 чанков

- Окружение: `.venv` поднят в корне ворктри (Python 3.13,

- **Шаг 2 (embedding + векторная БД + query CLI) реализован и проверен на
